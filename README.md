# Etios · Nafta

App simple para registrar las cargas de nafta del Etios y calcular el consumo.

Por cada carga guarda: fecha y hora (automática), litros, plata gastada y km del odómetro.
Calcula L/100 km, km por litro, $ por km y $ por litro.

- Un solo archivo: `index.html`. Se abre en el celular o la compu.
- Los datos quedan en el aparato (no se suben a ningún lado). Usar "Descargar respaldo" de vez en cuando.
- El consumo se calcula entre cargas de "tanque lleno".

No subir respaldos (`etios-nafta-*.json`) a este repositorio.
